# Emerald Masonry, LLC – High-Converting Landing Page Build Brief

## Overview

This document outlines the structure, messaging, and business context for building a **high-converting landing page** for Emerald Masonry, LLC using modern UI components from v0 (shadcn/ui).

The goal is to create a **clean, professional, trust-driven website** that generates **qualified leads** through clear messaging, strong calls-to-action, and an interactive estimate tool.

---

## Tech Stack

* **UI Template:** v0.app (shadcn/ui)
* **Framework:** Next.js
* **Version Control:** GitHub
* **Deployment:** Vercel
